Mũi tên = "phụ thuộc vào". Các service nghiệp vụ chỉ biết interface llm.Provider và store.Queries; lifecycle.Registry giữ context huỷ được cho từng session.

5. State machine — Deadline 5 phút (server-authoritative)

Sự kiệnXử lý
Tạo deadlineINSERT deadlines(deadline_at = now + RESPONSE_TIMEOUT), đặt time.AfterFunc trong bộ nhớ, WS deadline.new.
User replyNếu cùng channel/thread có deadline PENDING → validator. Hợp lệ → RESOLVED, huỷ timer, deadline.updated.
Hết giờUPDATE có điều kiện status='PENDING' (chống race) → EXPIRED, INSERT warning, sessions.warnings++, SYSTEM message, WS warning.new + session.updated.
Server restartRecover() đọc mọi PENDING; quá hạn → expire ngay, chưa → đặt lại timer.
Session kết thúcContext session bị huỷ → mọi timer của session dừng.

Client chỉ hiển thị countdown từ deadlineAt; không thể "gian lận" vì quyết định nằm ở server.
